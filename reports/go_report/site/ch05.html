5.1 聚合器梯子

對應報告卡 1：所有結構都落在 0.60–0.63：整題監督的集合模型比 MLP 多 +0.005 到 +0.009，上限約 0.01

四個事先指定的門檻都不成立；只看長度的 r2_length_only 是 0.2265。這條線之後被 L1b 取代，集合模型沒有在新的 59 維特徵上重測；第 8 章把「r3_pma 接現行每局訊號」列為待排的對照。

六種逐手序列 encoder（conv、GRU、CTM、Transformer、Mamba、Mamba-3）用每局交叉熵加 base + Δ 的接法，全部落在 0.6705–0.6737，對 fused_opp 0.6735 都在雜訊內；逐手層級的順序訊號沒有傳到題目層。

聚合方式有小幅增益，但處理不了證據本身的解析度。

5.2 對手特徵

對應報告卡 2：帶有：加入對手 16 維後 CV 0.6735，fold 0 0.6716

l1b_score.py --opponent 用同一組 out-of-fold 模型評同一批對局裡另一色的落子，同樣做 16 維題目特徵。線上配對依實力，對手是目標玩家等級的第二次量測。

機制假說（未驗證）：目標玩家的棋風偏差在同一題的 n 局裡是常數，不隨 n 平均掉；對手是配對系統抽出的 n 個不同人，其偏差以 1/√n 抵消，所以對手 pmi 與標籤的相關反而更高。可檢驗的推論：對手欄的 split-half 相關應低於自己欄而增益不低——第 7 章的數字方向相符。

前提：測試集的局也是相近實力的線上配對。訓練資料的折只按目標玩家切，head 可能看過對手的其他棋；這條路徑 fold 0 抓不到，只能在 Public 榜上檢查。

對手特徵的增益和鑑別式 L1b 同一量級。

5.3 差值特徵與讓子資訊

對應報告卡 3：能：差值 3 維 +0.0181 到 0.6916；HD 5 維再 +0.0071 到 0.6987

加差值後殘差對（對手 − 自己）的相關從 −0.213 降到 −0.130，模型學到了那一欄的主要線性部分。HD 的增益在「含讓子局」的題最大（0.6348 → 0.6507），符合它是標籤側資訊的預期；能不能用在正式提交，要看 11/04 的測試檔有沒有帶 HD[]。

提交候選 rank_model_fused_opp_diff.json（fold 0 0.6888）與退路 rank_model_fused_opp.json 都在 main；HD 版的文件要再用一次 fold 0，待使用者決定。

對手通道三步（對手、差值、讓子）是目前全部的有效改進；它們都依賴「測試局也是配對產生」這個前提。

本章結論

聚合器的增益上限約 0.01；對手通道兩步共 +0.036，HD 5 維再 +0.0071。提交候選 fused_opp_diff：CV 0.6916、fold 0 0.6888。
