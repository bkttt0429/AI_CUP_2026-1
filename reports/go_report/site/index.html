目前結果

現行提交模型 fused_opp 在 folds 1–4 CV 是 0.6735，在未參與任何選擇的 fold 0 是 0.6716，同一組 fold 0 題上官方 baseline 是 0.440。兩次真正的跳升都來自訓練每手證據模型與增加證據來源，換聚合器與最後一層都沒有明顯增益。

這些都是離線題上的分數，不能直接和排行榜比；官方 baseline 在 Public 是 0.4631。
