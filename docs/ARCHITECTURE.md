## 1. 問題本質

### 1.1 形式化

- 一題查詢 \(Q=\{(G_1,c_1),\dots,(G_m,c_m)\}\)：同一位**未知玩家**的 \(m\in[5,20]\) 局棋譜，每局附該玩家執色 \(c_i\)。棋譜只含落子（19 路、黑先、交替），沒有勝負、貼目、用時、對手資訊。
- 目標：預測該玩家的棋力等級 \(k\in\{0,\dots,9\}\)，順序 D, C, B, A, 1D–6D（D = 10–12k … A = 1–3k，段位各一段）。
- 得分：\(s(\hat k,k)=\mathbf 1[\hat k=k]+e^{-1}\,\mathbf 1[|\hat k-k|=1]\)，取平均。Public／Private 各 400 題，排名看 Private。
- 訓練資料：100 萬列 (player_id, game_id, rank, color, sgf)，8,007 位玩家，**每位玩家只屬一個等級**；對手不在資料集中、等級未知。

### 1.2 這個問題的本質是什麼

1. **是對「人」的推論，不是對「局」的分類。** 等級是玩家的屬性；每一局是這個屬性的一次不完整、有雜訊的觀測。對手的落子決定了局面怎麼走，但對手的等級未知，所以局面本身是混淆變數：同樣一個局面，可能是因為自己弱、也可能是因為對手強才走到的。
2. **全部訊號都在「給定局面，這個人選了哪一手」。** SGF 只有落子，所以能用的資訊只有條件分布 \(p(a\mid H,k)\)：不同等級的人面對相同局面，選點分布不同。沒有勝負、沒有目數、沒有時間，任何「結果」特徵都不存在。
3. **單一手的證據很弱，必須累積。** 相鄰等級（尤其 3D／4D 這類一段之差）在 \(p(a\mid H,k)\) 上只有微小位移，一手的似然比接近 1；要靠一局約 110 手、一題 5–20 局把證據累積起來。所以問題天然分解成：**逐手證據 → 整局 → 整題 → 校準後的後驗 → 在 ±1 計分下決策**。
4. **類別是有序的、寬度不均的。** 級位四類各跨 3 級，段位六類各跨 1 段，所以段位之間本來就更難分；計分給相鄰一級 \(e^{-1}\)，代表「接近」有價值，決策不該只看 argmax。
5. **要對未見過的玩家泛化。** 測試玩家是否在訓練集出現未知（11/04 才知道）；設計上要假設未見。玩家個人風格是和等級糾纏的潛變數，任何會記住「這個人」的東西都會在未見玩家上失效。
6. **證據不獨立。** 同一玩家的落子共享風格、同一局的落子共享局面脈絡，所以把逐手似然直接相加會**過度自信**；校準不是修飾，是這個問題的一部分。
7. **干擾因素有幾個已知的**：對手等級（未知）、局長（與等級單調相關，弱但合法）、執色、資料來源伺服器與年代（影響外部模型的轉移）。

### 1.3 我們下的賭注（可被 pilot 推翻的假設）

| 假設 | 內容 | 誰來驗證 |
| --- | --- | --- |
| H1 | 逐手似然 \(\log p(a\mid H,k)\) 累積後，能在未見玩家上分開相鄰等級 | Human SL pilot（METHOD_NOTES §2.4.1）→ **部分成立**（10/16）：相鄰 AUC 0.62–0.89、Spearman 0.94；fold 1 門檻 → fold 0 官方分 0.59／0.60／0.65（5／10／20 局）；1D｜2D、3D｜4D 弱 |
| H2 | 用本資料 1.11 億個有等級標籤的目標落子自訓的條件模型，勝過轉移來的 Human SL（域與等級尺度都不同） | 自訓模型 vs Human SL 的分組驗證 |
| H3 | 聚合、校準與期望得分決策，在 argmax 之上還有可量測的得分 | 校準 ablation |
| H4（可選） | 超越累加的條件式集合聚合有增益 | 聚合器梯子（METHOD_NOTES §2.7） |

### 2.1 每一層解決什麼

| 層 | 解決的子問題 | 為什麼這樣設計 | 現況 |
| --- | --- | --- | --- |

### 2.2 組合起來是什麼

- **零樣本管線（pilot，第 1 週）**：L1a（18 個 profile）→ L2 相加 → L3(0) → L4 硬分箱（D=10–12k…）取箱內最大、不擬合任何參數 → L5。回答 H1，產生第一個可提交的答案。
- **主提交候選（第 2–4 週）**：L1b → L2 相加 → L3(0) → L4 溫度 + \(\alpha\)（fold 1–4 擬合）→ L5。回答 H2、H3。
- **晚期融合**：L1a 與 L1b 各自校準後的 log 後驗加權平均（權重在 out-of-fold 上定）；若有 L1c 再加一路。解的是「轉移先驗」與「域貼合」的錯誤互補。
- **聚合器支線（可選，第 4 週起）**：固定 L1 特徵（快取）、換 L3 的梯子逐階比較，以玩家為單位成對檢定；只在 (3) 顯示集合互動有益時做 (4)(5)。回答 H4。
- **官方 baseline 的位置**：它是「整局 500 層平面 → ResNet → \(P(k\mid\text{局})\) → softmax 平均」，等於跳過 L1 的逐手分解、不區分目標玩家、L3 用平均、沒有 L4、L5 用 argmax。我們會在新驗證協議下重跑它一次當參考點（不是為了比它，是為了讓後面的改動有可歸因的差值）。
